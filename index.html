10 / FAQ

Frequently Asked Questions

Common questions about JEBAT command layer architecture, privacy postures, and enterprise deployment options.

What is JEBAT and how does it fit into my stack?
JEBAT is a sovereign AI command layer that sits between your applications and LLM providers. It decouples your agentic logic from specific model providers, manages persistent long-term memory via Ghost DB, dispatches native tools via MCP, and enforces security policies.
Can JEBAT run 100% air-gapped on private hardware?
Yes. In an air-gapped deployment, JEBAT operates with zero external network connectivity. Inference runs on your local GPU cluster via llama.cpp or Ollama, vector search operates locally in pgvector, and external telemetry is completely disabled.
What memory types does Ghost DB support?
Ghost DB provides 6 persistent memory modalities: Episodic (conversations), Vector (semantic embeddings), Working (active context window), Entity (knowledge graphs & relationships), Procedural (tool invocation patterns), and Semantic (curated knowledge bases).
How does NusaByte support enterprise deployments?
