# LEARNINGS.md — JEBAT Discoveries & Reusable Patterns

## 2026-10-07: SOGo Dynamic DOM Augmentation & MutationObserver Safety
- **Anti-Pattern:** Setting a `MutationObserver` on `document.body` or `document.documentElement` with `{ attributes: true }` when the observer callback mutates attributes (e.g. `img.src = ...`, `btn.setAttribute(...)`, `div.className = ...`).
- **Failure Mode:** Triggers an infinite recursive re-entrant loop inside the browser's JavaScript event loop, driving CPU to 100% and completely freezing the renderer thread before Angular can bootstrap.
- **Rule:** Never observe `attributes: true` unless strictly needed and guarded by element-level exclusion filters. Observe `{ childList: true, subtree: true }` only, with an atomic re-entrancy lock (`var isApplying = false; if (isApplying) return;`) and a debounced scheduler (`setTimeout` 150ms).

## 2026-10-07: Mailcow SOGo Authentication & `_sogo_static_view`
- **Architecture:** Mailcow's SOGo container uses a MySQL table `_sogo_static_view` (which is a base table, not a real database view) to authenticate user credentials.
- **Gotcha:** Updating `mailbox.password` via the Mailcow API or direct SQL does not automatically update `_sogo_static_view.c_password` if triggers fail or schemas diverge. If SOGo returns `LDAPPasswordPolicyError: 65535` despite IMAP logins succeeding on port 993, check `_sogo_static_view.c_password`.
- **Fix:** Update `_sogo_static_view SET c_password = (SELECT password FROM mailbox WHERE username = '...')`, flush Dovecot auth cache via `doveadm auth cache flush`, and flush Memcached via `echo flush_all | nc -w1 memcached 11211`.

## 2026-10-07: Iframe Ready Handshake Protocol
- **Pattern:** When embedding cross-origin or same-origin heavy SPAs (like SOGo) inside Next.js dashboards, never rely solely on `window.postMessage`.
- **Why:** If the embedded script fails, postMessage never fires and the loading spinner hangs forever.
- **Rule:** Implement a dual-trigger pattern:
  1. Primary: `postMessage({ type: 'component-ready' })` for precision.
  2. Fallback: `<iframe onLoad={() => setStatus('ready')} />` on the DOM element so any successful HTTP response immediately clears the loading state.

## 2026-10-08 (evening) — CetakTshirt gallery + Google-reviews build: tooling & caching traps
- **Turbopack dev image cache lives at `.next/dev/cache/images`** (NOT just `.next/cache/images`). It is URL-keyed: replacing a file under an identical `/testimoni/...` path keeps serving the STALE optimized bytes even after `rm -rf .next/cache/images` + server restart — the old process repopulates the disk cache before dying. - **Shared managed Chromium caches image URLs across tabs** — after a server-side image change, screenshots stay stale until CDP `Network.clearBrowserCache` + `reload({ignoreCache:true})`. Do this before image-change verification shots.

- **omp `read` dedupes identical image output** ("received this identical output 3 times") and can mislead when tracking re-rendered files — verify bytes via md5 + fresh-named copies when images are the test artifact.
- **Placeholder face sourcing (when jebat MCP image bridge is down):** `thispersondoesnotexist.com` serves an HTML wall to curl; `fakeface.rest` is dead (domain for sale); `i.pravatar.cc/700?img=N` works (real-photo stock, 700px); randomuser.me portraits are only 128px (too small for card headers). ## 2026-10-10 — Erawan QPOS: Nginx keepalive, SSE rate-limiting & advance sub-room locking
* 2026-10-10 - **SSE endpoints must be exempt from request rate-limiting**: Server-Sent Events (`/api/live-matrix/events`) are long-lived streaming connections. Placing `limit_req` with a burst cap on them causes 503 drops when multiple branch devices connect simultaneously. Once dropped, clients enter retry loops that exhaust the API burst pool. Remove `limit_req` from SSE and relax general store rate limits to 120r/s (burst 200).
* 2026-10-10 - **Upstream keepalive connection pooling for localhost reverse proxies**: Standard `proxy_pass http://127.0.0.1:4001;` opens a fresh TCP socket per request. Defining `upstream erawan_api_backend { server 127.0.0.1:4001; keepalive 64; }` with `proxy_http_version 1.1; proxy_set_header Connection "";` reuses socket pools, reducing request latency by 50-70% and eliminating socket exhaustion.
* 2026-10-10 - **Synchronous head guards for development Service Worker eviction**: Any cleanup in React's `useEffect()` is vulnerable to chunk load failures. If a stale service worker blocks the root layout chunk, `useEffect()` never runs.
